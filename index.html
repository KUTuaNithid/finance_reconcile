📊 Financial Statement Abbreviations
  • FS — Financial Statements (งบการเงิน)
  • BS — Balance Sheet (งบฐานะการเงิน)
  • PL — Profit & Loss (งบกำไรขาดทุน)
  • EQ — Statement of Changes in Equity
  • GL — General Ledger (บัญชีแยกประเภท)
  • TB — Trial Balance (งบทดลอง)
  • BF — Brought Forward (ยอดยกมา)
🔧 Config Field Reference
  • bs_debit — สินทรัพย์ (FS Value = BS Debit − BS Credit)
  • bs_credit — หนี้สิน/ทุน (FS Value = BS Credit − BS Debit)
  • pl_debit — ค่าใช้จ่าย (FS Value = PL Debit − PL Credit)
  • pl_credit — รายได้ (FS Value = PL Credit − PL Debit)
📐 Structure Row Types
  • header — แถวหัวข้อ (ไม่มีตัวเลข)
  • item — แถวรายการ
  • subtotal — แถวรวมย่อย
  • spacer — แถวว่าง
